# Company Employee Management API

A REST API project built using Django REST Framework for managing companies and employees.

## Features

- Company Management API
- Employee Management API
- CRUD Operations
- Foreign Key Relationship
- Admin-based Access
- RESTful APIs

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- Postman

## Company Fields

- id
- name
- location
- about
- type
- created_date

## Employee Fields

- name
- email
- address
- phone
- about
- position
- company

## API Testing

Tested APIs using Postman.
